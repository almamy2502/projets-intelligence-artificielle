# ESTIAM L3 - SQL
## Chapitre 1 : Introduction à SQL

### 1. Qu'est-ce que SQL ?
SQL signifie Structured Query Language.
C'est un langage qui permet de communiquer avec
les bases de données.

### 2. Les principales commandes

SELECT : récupérer des données.
FROM : indiquer la table.
WHERE : filtrer les résultats.
ORDER BY : trier les résultats.
GROUP BY : regrouper les données.

### 3. Exemple pratique

SELECT *
FROM etudiants;

Cette requête affiche tous les étudiants.

### 4. Exemple avec condition

SELECT *
FROM etudiants
WHERE age > 21;

Cette requête affiche les étudiants âgés
de plus de 21 ans.
